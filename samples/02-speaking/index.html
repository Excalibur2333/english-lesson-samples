课文 点哪句听哪句

要点：观点 + because + 理由

别人问你的想法时，只回一个词（“The park.”）对话就断了。说完整的两半句：

观点Opinion
+
because
+
理由Reason

I think we should go to the park, because the weather is nice.

  • I think we should … 我觉得我们应该……（提建议）
  • I’d like to … 我想要……（说自己想做的）
  • I prefer … 我更喜欢……（二选一时）
  • What about you? 说完把问题抛回去，对话才接得下去
  • That’s a good idea, because … 同意别人的主意，也要给理由
  • I’m not sure, because … How about …? 客气地不同意，再提一个新建议

2分步练：从跟读走到自己说

三小步，一步比一步放手。

第 1 小步 · 跟读 照着说

先听示范，再自己说一遍。录了音可以和示范对比着听。

第 2 小步 · 判断配对 分清观点和理由

第 3 小步 · 只看提示，自己说 不给句子了

这一步没有现成的句子可以照着读：看提示，自己把整句说出来，再对参考答案。
